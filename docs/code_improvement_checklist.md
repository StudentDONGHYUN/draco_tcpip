# 코드 개선 체크리스트

이 문서는 `docs/code_improvement_review.md`에 정리된 권장 사항과 후속 작업을 구현할 때 참고하는 체크리스트입니다. 각 항목은 적용 여부와 관련 변경 사항을 간략히 설명하고, 향후 재검토 시 메모를 남길 수 있는 공간을 제공합니다.

## 권장 사항 이행 현황

- [x] **MSG_EOF 송수신 핸드셰이크 도입**
  - 관련 파일: `nodes/stream_client.py`, `nodes/stream_server.py`
  - 요약: 클라이언트가 스트림 종료 시 `MSG_EOF`를 전송하고 서버가 이를 인지해 연결을 정리하도록 프로토콜을 강화함.
  - 메모: 필요 시 재연결 시나리오 테스트 추가 고려.

- [x] **파일 감시 로직의 이벤트 기반 전환**
  - 관련 파일: `nodes/stream_client.py`
  - 요약: inotify 기반 `SpoolWatcher`를 추가하고, 폴백으로 폴링을 유지하되 처리 기록을 제한해 메모리 사용량을 제어함.
  - 메모: 비 Linux 환경에서 폴백 경로 성능 검증 필요.

- [x] **config.py 경로 탐색 안전화**
  - 관련 파일: `utils/config.py`
  - 요약: 얕은 설치 경로에서도 IndexError 없이 루트 탐색이 가능하도록 보호 로직을 도입함.
  - 메모: 사이트 패키지 배포 형태에 대한 회귀 테스트 유지.

- [x] **socket reuse_port 예외 처리 추가**
  - 관련 파일: `nodes/stream_server.py`
  - 요약: `SO_REUSEPORT`를 지원하지 않는 커널에서 예외를 처리하고 기본 설정으로 재시도하도록 변경함.
  - 메모: Windows/WSL 환경에서의 동작 검증 예정.

- [x] **decode_drc() 임시 파일 정리 개선**
  - 관련 파일: `nodes/stream_server.py`
  - 요약: 디코딩 후 생성된 임시 파일을 정리해 작업 디렉터리 누적을 방지함.
  - 메모: 장기 세션에서 디스크 사용량 모니터링.

## 향후 점검 항목

- [ ] README 및 운영 문서에 새 정리 정책(`decode_drc` 파일 정리 동작)과 MSG_EOF 사용법을 문서화.
- [ ] 이벤트 기반 감시가 비활성화된 플랫폼에서의 성능 측정 및 최적화.
- [ ] 신규 기능(EOF 핸드셰이크, 감시자 등)에 대한 통합 테스트/엔드투엔드 시나리오 추가.
- [ ] 서버 소켓 예외 처리 경로에 대한 로깅 개선 여부 평가.

체크리스트는 변경 사항 반영 시마다 업데이트하고, 완료된 항목은 `[x]`로 표시합니다.
